# Documentation privacy

- Never include real company or customer names in repository documentation,
  comments, examples, test labels or fixture descriptions.
- This also applies to abbreviations, identifying environment names, local paths
  and statements that a named organization's data is absent or excluded.
- Use neutral labels such as `project-1`, `instance-1` or `external capture`.
  Do not invent company names as examples of this rule.
- Keep external replay paths and project identities configurable instead of
  embedding them in repository files. Preserve measurements and test assertions.
- Check changed files for identifying names before finishing documentation work.
