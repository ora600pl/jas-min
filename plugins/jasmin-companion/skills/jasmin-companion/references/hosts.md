# Opening the panel

Use the integration for the application running this conversation. Keep the MCP process alive: its returned `panel_url` identifies the live session and its in-memory evidence. Starting `server.mjs --preview` opens a separate synthetic session and cannot display the conversation's evidence.

## Codex

Display `panel_url` with `open_in_codex`, browser target. The portable `mcp.json` uses contained `./launch.sh`; do not replace it with an absolute executable path. Use the desktop's bundled CLI for installation and compatibility checks.

## Claude Code Desktop and terminal

Use a local Code session. The plugin's MCP tool names may have a host-added prefix; discover the actual tools by their `companion_*` suffixes. Invoke the skill as `/jasmin-companion:jasmin-companion` when needed.

Open the exact `panel_url` returned by `companion_open`. If this Desktop session exposes browser tools that can navigate to a local URL, use those tools. Otherwise open that URL in the system browser (on macOS, `open '<panel_url>'`) and keep the panel beside the conversation. Quote the complete URL as one shell argument. A clickable link in the local chat is also a usable fallback. Do not call Codex-only tools, invent a browser tool, or claim the panel is embedded before observing it.

The MCP process already serves the live panel. Do not launch another server, overwrite a project's preview configuration, or expose the loopback port publicly to display it. Ordinary Claude chat, Cowork and cloud Code sessions are outside this local Code integration. Native voice availability depends on the host; the plugin itself supplies no voice controls.

Claude loads `.claude-plugin/plugin.json`; its inline `companion` MCP entry uses `node` and `${CLAUDE_PLUGIN_ROOT}/server.mjs`. It takes precedence over the same server name in the ignored `.mcp.json` generated by the Codex installer. Keep the inline entry portable. After installing or updating, start a new local Code session and inspect its loaded tools. A refreshed browser alone cannot reload the MCP server or skill.
